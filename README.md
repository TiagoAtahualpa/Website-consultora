## 📋 Descrição do Projeto

Desenvolvimento completo de um site institucional estático para a empresa de consultoria e recrutamento **Bedregal Consultora**. Este projeto foi concebido a partir de uma necessidade real de mercado, com foco em criar uma presença digital sólida, profissional e voltada para a conversão de novos clientes. 

O site foi construído totalmente do zero através de uma arquitetura multi-página, priorizando a alta performance, a modularidade do código e a ausência de frameworks pesados, garantindo uma experiência de usuário (UX) otimizada e fluida em desktops, tablets e smartphones.

---

## ✨ Principais Funcionalidades 

- **Design 100% Responsivo:** Layout fluido que se adapta perfeitamente a qualquer tamanho de tela utilizando CSS moderno e Media Queries.
- **Menu de Navegação Interativo (Manipulação do DOM):** Menu lateral mobile dinâmico com submenus em formato "acordeão", desenvolvido com lógica robusta em JavaScript nativo.
- **Estrutura Multi-página Escalável:** Arquitetura clara dividida em Home, Sobre Nós, Serviços (com páginas dedicadas para cada sub-serviço) e canal direto de Contato.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica avançada para melhor acessibilidade e indexação de SEO.
- **SCSS / SASS:** Utilizado para a modularização do CSS, herança de estilos, variáveis e organização eficiente da arquitetura de arquivos, facilitando a manutenção global do projeto.
- **Vanilla JavaScript:** Interatividade nativa e manipulação eficiente do DOM, garantindo leveza ao carregar os scripts (sem dependência de bibliotecas externas).
- **Font Awesome:** Ícones vetoriais leves para a interface.
- **Git / GitHub:** Controle de versionamento e deploy de homologação.
- **Hospedagem & cPanel:** Configuração e publicação final em ambiente de produção para o cliente.

## 🧠 Desafios Técnicos e Aprendizados

Este projeto foi uma excelente oportunidade para solidificar conceitos de engenharia de software no front-end e enfrentar desafios práticos comuns do desenvolvimento web de mercado:

- **Arquitetura de CSS Modular com SCSS:** Desafio de gerenciar a especificidade do CSS e reaproveitar estilos globais em um projeto multi-página, mantendo as folhas de estilo organizadas, limpas e escaláveis.
- **Layouts Complexos do Zero:** Domínio técnico na combinação de Flexbox para alinhamento de componentes internos e CSS Grid para a estrutura macro das seções institucionais.
- **Lógica de Interface com JavaScript Nativo:** Implementação manual de eventos de clique, controle de classes estruturais do CSS via JS para transições suaves do menu hambúrguer e manipulação de estados do submenu acordeão.
- **Deploy e Fluxo de Produção:** Entendimento prático do fluxo de deploy, gerenciando um ambiente de testes (GitHub Pages) simultaneamente à publicação oficial em servidor Linux via cPanel, lidando com permissões de arquivos e caminhos de diretórios.
- **Performance e Otimização:** Foco total em manter o site extremamente leve, otimizando o carregamento de imagens e scripts para garantir uma excelente pontuação de performance em dispositivos móveis.
